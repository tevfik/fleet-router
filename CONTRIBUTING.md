# Contributing

Issues and pull requests are welcome.

- Read [AGENTS.md](AGENTS.md): layout, how to build and test, the rules.
- Every change comes with a test; `make check` and `FLEET_RUNNER=0 go test ./...` must pass.
- Keep pull requests small and about one thing.
